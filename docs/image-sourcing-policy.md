# 한국플레이리스트 이미지 제작 최종 기준

확정일: 2026-09-16. 앞으로 작성하는 한국어·영어·일본어 글에 동일하게 적용합니다. 기존 글·이미지는 별도 승인 없이 변경하지 않습니다.

## 기획
- 대표 이미지와 본문 이미지의 목적·위치·관련 문단을 미리 정합니다. 대표 한 장으로 자동 종료하거나 숫자만 채우지 않습니다.
- 실제 시설·동선·전시를 보여줘야 한다면 권한과 촬영 장소가 확인된 실제 사진을 우선합니다.
- 생성 이미지는 기본적으로 실사풍으로 제작하되, 실제 제공하지 않는 시설·서비스·체험을 사실처럼 표현하지 않습니다.

## 생성 전 권한 확인
- 직접 보유한 권리, 명시적인 허락 또는 이미지 자체에 적용되는 퍼블릭 도메인·적합한 라이선스를 확인합니다.
- 원본 페이지·파일 URL, 저작자, 라이선스 이름·근거 URL, 확인일, 상업적 이용·변형·참고 입력 가능 여부, 필수 표시와 제한을 기록합니다.
- 공식 기관·포토코리아·제휴업체·검색 결과의 사진도 개별 조건을 확인합니다. 사이트 하단의 데이터 라이선스를 사진에 적용하지 않습니다.
- 비상업적 이용 전용, 변경 금지, 출처 불명, 참고 입력 권한 불명 자료는 생성 도구에 넣지 않습니다.
- 사진 이용 허락이 인물의 초상·개인정보, 상표, 작품·전시 조형물 등 별도 권리까지 보장하는 것은 아닙니다. 필요한 추가 확인을 마칩니다.
- 여러 사진 혼합, AI 생성, 자르기·반전·색상·각도 변경은 권한 확인의 대안이 아닙니다.
- 권리나 과도한 유사성이 불분명하면 발행 보류합니다. 저작권 위험이 전혀 없다고 보증하지 않습니다.

## 생성 프롬프트
매번 이미지의 설명 목적, 권한 검토가 끝난 참고자료, 허용 참고 범위, 새 구도·시점·빛·인물 행동, 복제하지 않을 요소를 명시합니다.

> 허용된 참고자료의 일반적인 재질·채광을 참고하되 새 구도와 장면을 설계한다. 특정 사진의 독특한 표현, 인물, 상표, 문구, 작품과 전시 구조를 그대로 재현하지 않는다. 가짜 예약 화면·입장권·공식 표지·방문 증거를 만들지 않는다. 자연스러운 실사풍으로 제작하며 실제 현장과 연출 장면을 구분한다. 결과를 참고자료와 대조해 검수한다.

프롬프트 자체가 권리 확인이나 결과 검수를 대신하지 않습니다. 사용자가 별도로 요청하지 않으면 만화·설명 그림을 기본으로 만들지 않습니다.

## 표시
- 자체 생성 이미지의 짧은 표시 문구는 `한국플레이리스트`로 통일합니다. 이 문구는 권리 취득이나 법적 면책을 의미하지 않습니다.
- 제3자 자료의 필수 저작자·출처·라이선스 표시는 생략하거나 사이트 이름으로 대체하지 않습니다. 조건을 충족할 수 없으면 사용하지 않습니다.
- 현장 사진으로 혼동될 수 있는 생성 이미지는 눈에 보이는 본문 안내로 AI 연출임을 밝힙니다. 대체 텍스트와 내부 기록도 남기되 숨겨진 정보만으로 대신하지 않습니다.
- 대체 텍스트는 실제 보이는 장면을 설명하며 확인되지 않은 장소명·키워드를 넣지 않습니다.
- 생성 도구·프롬프트·참고자료·결과 파일·검수와 제한 사항을 감사 기록에 남깁니다.

## 검수와 발행
- 원본과 구도·배치·독특한 표현의 유사성을 검수합니다. 판단이 어려우면 발행하지 않습니다.
- 손·얼굴·문구·시설 묘사 오류를 확인하고 사진을 이름만 바꿔 중복 사용하지 않습니다.
- 새 파일만 `public/images/generated/`에 저장하고 필요한 WebP 변형만 `public/images/optimized/generated/`에 만듭니다. 일괄 이미지 재생성은 하지 않습니다.
- 모바일·PC에서 선명도·잘림·로딩·표시·문단 관련성을 확인하고, 빌드와 공개 이미지 응답을 검증합니다.
- 교체가 승인된 문제 이미지는 현재 웹 배포 대상에서 제외하고 별도 보관할 수 있습니다. Git 기록·캐시·과거 배포까지 제거됐다고 단정하지 않습니다.
